Every request the browser makes, read, analyzed, reproduced.

rever-browser is a desktop app that puts what web reversing needs inside the browser itself. Traffic capture, bundle deobfuscation, crypto tracing, repeater and intruder, an upstream proxy, a session that stays logged in, and an element picker that hands you a target to act on — all in one window. An agent that knows the order of the work sits next to it and walks the tedious stretches for you. Every tool is exposed over MCP, so external agents and scripts can drive the same surface.

    02 what's inside
    
      
    
        
    Browser control, packet capture, a proxy, and an agent reading all of it.
    
        
    Nothing to wire up. The capture buffer, the proxy, the bundle analyzer and the tool server all live in the same window as the tab you are driving.
    
      
    
    
    

    
    
      
    
        
    01
    
        
    Live traffic capture
    
        
    
          
    Every Network.* event from the tab lands in a ring buffer. Response bodies are fetched lazily on loadingFinished, and image, video, font and CSS payloads are skipped so the buffer stays readable.
    
          
    cdpring bufferlazy bodieshar export
    
        
    
      
    
      
    
        
    02
    
        
    Proxy and a session that stays logged in
    
        
    
          
    Point tabs at an upstream proxy over http, https or socks5, with auth. The change applies to the live session, so nothing needs remounting.
    
          
    Ordinary tabs share one persistent partition, so logging in once carries over to tabs you open from it. Proxy tabs are the exception: each gets its own cookie jar, which lets you hold two identities on the same site at the same time.
    
          
    http · https · socks5proxy authpersistent cookiesper-tab isolation
    
        
    
      
    
      
    
        
    03
    
        
    Element picker — grab it on screen, act on it
    
        
    
          
    Inspect mode like devtools: pick an element on the page and its selector comes back to you. Ask for that element to be clicked, or for the request it fires to be captured, without leaving the chat.
    
          
    inspect modeselector copysend to chat
    
        
    
      
    
      
    
        
    04
    
        
    Browser control that survives real pages
    
        
    
          
    Navigate, click, type, scroll, drag, press keys and upload files — all as tools, and the target is a short rN ref from the snapshot rather than a brittle selector.
    
          
    It reaches elements the accessibility tree never exposes, pierces shadow roots, and drives nested out-of-process iframes. The snapshot only emits what is actually painted, and scrolling uses real wheel input, so infinite scrollers behave.
    
          
    browser_snapshotbrowser_clickbrowser_dragbrowser_wait_forshadow domoopif
    
        
    
      
    
      
    
        
    05
    
        
    Bundle analysis without a re-download
    
        
    
          
    Grep, extract, detect the bundler and deobfuscate the JavaScript already sitting in the capture. webcrack unminifies when it is on your PATH, and source maps are restored when the site ships them.
    
          
    grep_scriptsdetect_bundlerdeobfuscate_scriptsourcemap
    
        
    
      
    
      
    
        
    06
    
        
    The rest of the reversing kit
    
        
    
          
    Repeat a request with edits, sweep values with the intruder, override headers, intercept and rewrite in flight. Crypto and encoding helpers, secret scanning, WebSocket and service-worker inspection, GraphQL and protobuf readers — same window.
    
          
    repeaterintruderinterceptcryptosecretsgraphqlprotobuf
    
        
    
      
    
      
    
        
    07
    
        
    Macros — replay a verified sequence exactly
    
        
    
          
    Save the run you just checked — login through to the list call — and it replays step for step without going near a model. Credentials and other changing values stay as variables, filled in at run time.
    
          
    The result is the same every time, which is what regression checks and repeated collection need.
    
          
    macro_recordmacro_runvariableszero model calls
    
        
    
      
    
      
    
        
    08
    
        
    Workflows — several steps as one
    
        
    
          
    Chain macros and tool calls into a single workflow. The status bar shows where the run is, and what it finds along the way lands in the findings list.
    
          
    workflowsfindingshar export
    
        
    
      
    
      
    
        
    09
    
        
    An agent for the tedious stretches
    
        
    
          
    Claude Code by default, Codex as an alternative, both over ACP on stdio. The agent reads the same traffic store the UI renders, so “explain the request I just made” needs no copy-paste.
    
          
    Want a different model or a different agent? Fork it, add yours and send a pull request — the agent list lives in one file.
    
          
    acpclaude-agent-acpcodex-acpcontributions welcome
    
        
    
      
    
      
    
        
    10
    
        
    Local by default
    
        
    
          
    The MCP server is in-process, binds to a random port on 127.0.0.1, and starts lazily on the first agent spawn. Captured traffic stays in memory inside your own app.
    
          
    127.0.0.1in-processno analytics backend

    05 quickstart
    
      
    
        
    Running in about a minute.
    
        
    Bun is the package manager, not npm or pnpm. The agent binary installs separately because it runs as its own process.
    
      
    
    
    

    
    
      
    
        
    zsh
    

    # 0 — or skip the build: download the packaged macOS app
#     https://github.com/greekr4/rever-browser/releases/latest
#     arm64 = Apple Silicon, x64 = Intel. Drag it to Applications,
#     then clear the quarantine flag (the build is unsigned):
$ xattr -dr com.apple.quarantine "/Applications/Rever Browser.app"

# 1 — the agent binary, on your PATH
$ npm i -g @agentclientprotocol/claude-agent-acp

# 2 — the app
$ git clone https://github.com/greekr4/rever-browser
$ cd rever-browser
$ bun install
$ bun run dev

# optional — unminify captured bundles
$ npm i -g webcrack

    one thing first
    
      
    
        
    rever-browser is an open-source security testing tool. It was built to check what your own service's API gives away and whether its auth actually holds.
    
        
    It drives a real browser against real servers, so use it on services you run or on systems you have written permission to test, and follow the site's terms and your local law.
