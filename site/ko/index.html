브라우저가 주고받는 요청,에이전트가 읽고분석하고 재현합니다.

rever-browser는 웹 리버싱에 필요한 것들을 브라우저 안에 모아 둔 데스크톱 앱입니다. 트래픽 캡처, 번들 해독, 암호화 로직 추적, 리피터와 인트루더, 프록시, 세션 유지, 화면에서 요소를 집어 바로 요청 보내기까지 한 창에서 끝납니다. 여기에 리버싱 순서를 아는 에이전트가 붙어서, 손으로 하면 지루한 구간을 대신 밟아 줍니다. 도구는 전부 MCP로 열려 있어 외부 에이전트나 스크립트에서도 그대로 호출할 수 있습니다.

    리버싱 키트 리버싱에 필요한 도구 — 트래픽 캡처, 난독화 해제, 리피터, 인트루더 — 전부가 브라우저 하나 안에 들어 있습니다.

    01 시나리오

    채팅으로 요청하세요. AI가 브라우저를 직접 조작해서 찾아냅니다.

    개발자 도구를 열어 요청을 하나씩 눌러 보고, 파라미터를 바꿔 다시 던지는 과정을 대신합니다. 아래 시나리오는 앱 화면을 그대로 옮겨 만든 재현이고, 문장을 고르면 위쪽 화면이 그 장면을 다시 보여 줍니다.

    데모 불러오는 중…

    01 에이전트가 페이지를 스냅샷으로 뜨고, 검색 버튼을 누르고, 잡힌 트래픽을 읽어 엔드포인트를 찾아냅니다.

    02 무엇이 들어 있나
    
      
    
        
    브라우저 조작, 패킷 캡처, 프록시, 그리고 그걸 다 읽는 에이전트.
    
        
    따로 붙일 게 없습니다. 캡처 버퍼도, 프록시도, 번들 분석기도, 도구 서버도 지금 조작 중인 탭과 같은 창 안에 있습니다.
    
      
    
    
    

    
    
      
    
        
    01
    
        
    실시간 트래픽 캡처
    
        
    
          
    탭에서 발생한 Network.* 이벤트가 전부 링 버퍼에 쌓입니다. 응답 본문은 loadingFinished 시점에 필요할 때만 가져오고, 이미지·비디오·폰트·CSS는 건너뛰어서 버퍼가 읽을 만한 상태로 유지됩니다.
    
          
    cdpring bufferlazy bodieshar export
    
        
    
      
    
      
    
        
    02
    
        
    프록시와 세션 유지
    
        
    
          
    업스트림 프록시를 http·https·socks5로 걸 수 있고 인증도 붙습니다. 설정은 세션에 바로 적용돼서 탭을 다시 띄울 필요가 없습니다.
    
          
    일반 탭은 하나의 영구 파티션을 공유하기 때문에 한 번 로그인하면 새 탭에서도 그대로 유지됩니다. 프록시 탭만 별도 쿠키 저장소를 써서, 같은 사이트를 다른 신원으로 동시에 열어 둘 수 있습니다.
    
          
    http · https · socks5프록시 인증쿠키 유지탭별 격리
    
        
    
      
    
      
    
        
    03
    
        
    요소 선택기 — 화면에서 집어 바로 요청
    
        
    
          
    개발자 도구의 검사 모드처럼 화면에서 요소를 집으면 셀렉터가 그대로 넘어옵니다. 그 요소를 눌러 보라거나, 거기서 나가는 요청을 잡아 달라고 바로 이어서 시킬 수 있습니다.
    
          
    inspect 모드셀렉터 복사채팅으로 전달
    
        
    
      
    
      
    
        
    04
    
        
    브라우저 조작 — 실제 페이지에서 안 깨지게
    
        
    
          
    이동·클릭·입력·스크롤·드래그·키 입력·파일 업로드까지 도구로 나와 있고, 대상은 셀렉터 대신 스냅샷이 매긴 짧은 rN 참조로 지정합니다.
    
          
    접근성 트리에 안 잡히는 요소, Shadow DOM 안쪽, 중첩된 out-of-process iframe까지 들어가서 조작합니다. 스냅샷은 화면에 실제로 그려진 것만 내보내고, 스크롤은 합성 이벤트가 아니라 진짜 휠 입력이라 무한 스크롤도 정상 동작합니다.
    
          
    browser_snapshotbrowser_clickbrowser_dragbrowser_wait_forshadow domoopif
    
        
    
      
    
      
    
        
    05
    
        
    다시 내려받지 않는 번들 분석
    
        
    
          
    이미 캡처에 들어 있는 자바스크립트를 그대로 grep 하고, 추출하고, 번들러를 판별하고, 난독화를 풉니다. webcrack이 PATH에 있으면 압축을 풀어 주고, 사이트가 소스맵을 제공하면 원본을 복원합니다.
    
          
    grep_scriptsdetect_bundlerdeobfuscate_scriptsourcemap
    
        
    
      
    
      
    
        
    06
    
        
    리버싱에 쓰는 도구 한 벌
    
        
    
          
    리피터로 요청을 고쳐 다시 보내고, 인트루더로 값을 훑고, 헤더를 덮어쓰고, 요청을 가로채 중간에서 바꿉니다. 암호화·인코딩 해석, 시크릿 탐지, 웹소켓과 서비스 워커 점검, GraphQL·프로토버프 리더까지 같은 창에 있습니다.
    
          
    repeaterintruderinterceptcryptosecretsgraphqlprotobuf
    
        
    
      
    
      
    
        
    07
    
        
    매크로 — 한 번 확인한 절차를 그대로 재생
    
        
    
          
    로그인부터 목록 조회까지 방금 검증한 순서를 매크로로 저장해 두면, 다음부터는 모델을 거치지 않고 같은 절차가 그대로 실행됩니다. 아이디·비밀번호 같은 값은 변수로 빼두고 실행할 때 채웁니다.
    
          
    결과는 매번 같습니다. 회귀 확인이나 데이터 수집처럼 반복이 필요한 작업에 씁니다.
    
          
    macro_recordmacro_run변수 치환모델 호출 0
    
        
    
      
    
      
    
        
    08
    
        
    워크플로 — 여러 단계를 하나로 묶기
    
        
    
          
    매크로 여러 개와 도구 호출을 순서대로 엮어 하나의 워크플로로 만듭니다. 상태 표시줄에서 실행 상황을 보고, 중간 결과는 발견 목록에 쌓입니다.
    
          
    workflowsfindingshar export
    
        
    
      
    
      
    
        
    09
    
        
    지루한 구간을 대신 밟는 에이전트
    
        
    
          
    기본은 Claude Code, 대안으로 Codex를 쓸 수 있고 둘 다 stdio 위의 ACP로 붙습니다. 에이전트가 읽는 트래픽 저장소는 화면에 뜨는 것과 같은 저장소라, “방금 보낸 요청 설명해줘”에 복붙이 필요 없습니다.
    
          
    다른 모델이나 다른 에이전트를 붙이고 싶다면 저장소를 포크해서 추가하고 풀 리퀘스트를 보내주세요. 에이전트 목록은 파일 한 곳에서 관리합니다.
    
          
    acpclaude-agent-acpcodex-acp기여 환영
    
        
    
      
    
      
    
        
    10
    
        
    기본값이 로컬
    
        
    
          
    MCP 서버는 앱 안에서 돌고 127.0.0.1의 임의 포트에 붙습니다. 에이전트를 처음 띄울 때만 시작되고, 캡처한 트래픽은 사용자 컴퓨터의 앱 메모리에 머뭅니다.
    
          
    127.0.0.1in-process수집 서버 없음
    
        
    
      
    
    
    
  
    

    



    
  
    
    
    
      
    03 구조
    
      
    
        
    프로세스는 셋으로 나누고, 경계는 하나만 둡니다.

    04 도구 목록

    05 시작하기
    
      
    
        
    1분이면 실행됩니다.
    
        
    패키지 매니저는 npm이나 pnpm이 아니라 bun입니다. 에이전트 실행 파일은 별도 프로세스로 돌기 때문에 따로 설치합니다.
    
      
    
    
    

    
    
      
    
        
    zsh
    

    # 0 — 빌드 없이 바로 쓰려면: 패키징된 macOS 앱 다운로드
#     https://github.com/greekr4/rever-browser/releases/latest
#     arm64 = Apple Silicon, x64 = Intel. Applications로 드래그한 뒤
#     서명이 없어 걸리는 격리 속성을 해제하세요:
$ xattr -dr com.apple.quarantine "/Applications/Rever Browser.app"

# 1 — PATH에 올라가야 하는 에이전트 실행 파일
$ npm i -g @agentclientprotocol/claude-agent-acp

# 2 — 앱
$ git clone https://github.com/greekr4/rever-browser
$ cd rever-browser
$ bun install
$ bun run dev

# 선택 — 캡처한 번들 난독화 풀기
$ npm i -g webcrack
    
      
    

      
    
        
    01
    대상 사이트를 연다
    내장 탭 주소창에 URL을 넣습니다. 요청이 발생하는 대로 트래픽 목록에 쌓입니다.
    
        
    02
    채팅 패널을 연다
    Claude Code나 Codex를 고릅니다. 세션은 리버싱용 시스템 프롬프트가 이미 걸린 상태로 시작합니다.
    
        
    03
    물어본다
    “검색 엔드포인트는 뭘 받아?” 하면 에이전트가 캡처를 읽고 번들을 뒤진 뒤, 요청을 다시 보내 스스로 확인합니다.
    
        
    04
    남긴다
    매크로로 저장하거나, HAR로 내보내거나, 생성된 클라이언트 코드를 앱 밖에서 실행합니다.
